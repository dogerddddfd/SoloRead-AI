# 生词页实现计划

## 页面功能

1. **展示生词列表**：以列表形式展示用户添加的生词
2. **支持进入造句模式**：用户可以从生词列表中选择单词进入造句模式
3. **管理生词**：支持查看生词详情、删除生词等操作

## 实现步骤

### 1. 创建页面组件

- 在 `/src/screens` 目录下创建 `VocabularyScreen.tsx` 文件
- 实现页面基本布局，包括：
  - 生词列表
  - 空状态提示（当没有生词时）
  - 导航到造句页的入口

### 2. 实现生词数据获取

- 从数据库中获取所有生词
- 按一定顺序排序（如添加时间或复习频率）
- 处理数据加载状态

### 3. 实现生词列表展示

- 使用 FlatList 或 SectionList 展示生词列表
- 每个列表项包含：
  - 单词
  - 基本释义
  - 复习次数
  - 上次复习时间
- 支持下拉刷新和上拉加载（如果需要）

### 4. 实现造句模式入口

- 在生词列表项中添加进入造句模式的按钮
- 点击后导航到造句页，并传递选中的单词
- 或者提供一个统一的按钮，随机选择一个生词进入造句模式

### 5. 实现生词管理功能

- 支持删除生词
- 支持查看生词详情
- 支持标记生词为已掌握（如果需要）

### 6. 处理异常情况

- 处理数据库查询失败的情况
- 处理空数据的情况
- 处理删除操作的异常

### 7. 优化用户体验

- 添加加载动画
- 优化列表滚动性能
- 提供清晰的操作反馈
- 确保页面响应速度快

### 8. 测试功能

- 测试生词列表的展示
- 测试进入造句模式的功能
- 测试生词管理功能
- 测试各种异常情况的处理

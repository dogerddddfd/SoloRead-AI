# 环境搭建计划

## 1. 初始化 React Native 项目

- 使用 Expo 初始化项目
- 选择 TypeScript 模板以获得更好的类型支持

## 2. 安装核心依赖

- **React Native 核心**：react, react-native
- **SQLite**： expo-sqlite
- **本地存储**：@react-native-async-storage/async-storage
- **网络请求**： fetch API
- **UI 组件**：自定义组件

## 3. 配置项目结构

按照推荐的目录结构创建文件夹：

```
/src
  /ai            # AI 相关逻辑
  /database      # 数据库操作
  /dict          # 本地词典
  /screens       # 页面组件
  /components    # 通用组件
  /storage       # 存储相关
  /utils         # 工具函数
App.tsx
```

## 4. 配置权限

- 确保应用具有网络访问权限（用于 AI API 调用）
- 确保应用具有本地存储权限（用于 SQLite 和 AsyncStorage）



## 6. 配置开发环境

- 安装 Node.js 和 npm
- 配置 iOS/Android 开发环境
- 确保可以在模拟器或真机上运行应用

## 7. 初始化数据库

- 优先添加简单测试表作交付验证
---
- 创建数据库表结构
- 实现数据库初始化逻辑
- 确保应用启动时能正确初始化数据库
- 表格式参考/chat/design/db-design.md


## 9. 测试环境

- 确保应用能在 iOS 和 Android 平台正常运行
- 测试基本功能是否正常工作
- 确保数据库操作正常

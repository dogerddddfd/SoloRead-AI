
# LexLab Mobile

这是一个手机端应用 Vibe Code 项目。

目标：

* 手机上刷英语阅读
* 查词 + 生词 + 造句
* 本地优先
* 结构清晰
* 不做完整学习系统

不是商业产品，不追求完整度。

---

# 技术栈

* React Native
* SQLite（react-native-sqlite-storage 或 expo-sqlite）
* 本地精简词库（约 10 万词，约 5MB）
* 外部 AI API（用户填写）
* 本地持久化（AsyncStorage 仅用于设置）

不使用：

* 服务器
* 云同步
* 用户系统
* 第三方生词 API

---

# 项目范围

## 做

1. AI 生成英语阅读文章
2. 本地存储文章
3. 选词查词（离线词典优先）
4. 加入生词
5. 从生词抽词造句
6. AI 给造句反馈（仅参考）
7. 简单复习频率控制
8. 设置页（管理 API Key）

---

## 不做

* 阅读进度记录
* 书签系统
* 完整 SRS 算法
* 成功失败权重
* 动态难度
* 推荐算法
* 多设备同步

# 页面结构

## 1. 阅读页

* 输入主题
* 点击生成文章
* 展示文章
* 长按选词
* 弹出查词浮窗
* 可加入生词

---

## 2. 生词页

* 展示生词列表
* 支持进入造句模式

---

## 3. 造句页

* 抽取一个生词
* AI 生成简短场景
* 用户写完整句子
* AI 给反馈
* 可点击“我不会”生成例句

评分不影响复习逻辑。

---

## 4. 设置页（必须）

用于管理：

* AI API Key
* AI Base URL（可选）
* 默认模型名（可选）

规则：

* 设置使用 AsyncStorage 存储
* 不存入 SQLite
* 不上传到任何服务器
* 不做加密（Vibe 项目）

AI 调用前必须读取设置。

若未配置 API Key：

* 禁止调用 AI
* 提示用户前往设置页

---

# 复习逻辑（极简）

基于：

* 当前时间 - last_practiced_at
* review_count

目标：

* 久未练习优先
* 次数多的词降低出现概率

不区分对错。

---

# AI 使用规则

* 所有 AI 调用必须封装在 /ai 模块
* UI 不直接调用 AI
* 所有 AI 结果必须入库
* 禁止自动调用 AI
* 必须用户触发
